Pluck changelog

Notable changes by release tag.

v0.3.0

- Add a Settings window. Press F2 during capture or run Pluck.exe --settings to open it.
- Show a small F2 hint before selection. Hide the hint when you start to draw a rectangle.
- Install Pluck for the current Windows user, create capture and Settings shortcuts, and uninstall from Settings.
- Check for updates in Settings. Verify each download before replacing the installed application.
- Add a Pluck icon and use its colors in Settings.

v0.2.2

- Capture the desktop before selection starts to keep open menus in the copied image.
- Keep the same captured image when you try again after a clipboard error.

v0.2.1

- Make Escape cancel and quit before drawing when a keyboard shortcut or launcher does not give Pluck keyboard focus.

v0.2.0

- Stop the selection border and text from flashing when the pointer stays still.
- Remove the instruction text during selection. Show text only if copying fails.

v0.1.0

- Open directly in rectangle selection mode.
- Drag an area on the live desktop and release to copy its pixels to the clipboard.
- Exit after copying. Press Escape or right-click to cancel without changing the clipboard.
- Capture across connected displays in physical pixels.
- Ship one portable native Windows x64 executable.
